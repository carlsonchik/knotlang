# Словарь КНОТЛАНГа v0.7

Норма слов на момент канона v0.7. Правила, по которым собраны формы, — в `KNOTLANG.md`. Одна основа — одна строка. Пустая клетка `-` значит: этой формы нет.

Порядок слоёв в таблице: зреет (`-i-`), держится (`-u-`), отдаётся (`-a-`), откликается (`-e-`).

Модели:

| Код | Как строится форма |
|---|---|
| `A` | Единственная гласная основы заменяется гласной слоя. Если основа не кончается на `t` или `d`, в конце прибавляется `t`. |
| `B` | Гласная слоя прибавляется в конец, основа не трогается. |
| `CV` | Основа из согласной и гласной (`mo`, `cha`): гласная слоя прибавляется, и при совпадении гласных получается долгота (`chaa`). |
| `CVCV` | Конечная гласная заменяется гласной слоя (`rawi` → `rawu`). |
| `EXC` | Исключение `kafe`: гласная слоя прибавляется, как у `CV`, хотя гласных в основе две. |
| `SIB` | Только `tish`: после основы ставится слог `-it/-ut/-at/-et`. На другие корни не распространяется. |
| `FIX` | Предельное слово: форма во всех слоях одна и та же. |
| `NEAR` | Почтипредельное: слои есть, но не все. У `momor` нет формы `-a-`. |
| `COLOR` | Цвет. Нормативна только форма `-u-`, и она считается по тому же правилу, что тип `A` (если гласная не первая) или тип `B` (если гласная первая, как у `amr`). В согласовании цвет не участвует. |

Заметка у строки типа `B` обязательна там, где по форме основы ожидался бы тип `A`, а удержан суффикс. Это не ошибка таблицы, а записанное исключение.

Новых корней в v0.7 нет. Новые поверхностные формы (другие гласные уже известного корня, выправленные цвета) перечислены в `CHANGELOG.md`.

## Частицы

Частица не несёт слоговой гласной. В предложении она либо служебна (`nai`, `kne`), либо называет натяжение количества, не узел (`kam`, `tip`).

| слово | роль |
|---|---|
| nai | частица предиката: узел удержан; замыкает предложение |
| zhe | клитика одновременности; пишется только как nai-zhe |
| nashe | полная форма одновременности, отдельное слово |
| kne | вопрос-зов: откликнись |
| kni | приказ: втяни в центр то, что уже зреет |
| kna | префикс «в другом слое»; отдельно не стоит, только kna-форма |
| kam | несколько: количество ещё не развернулось |
| tip | мало: слой почти пуст |

`ves` (всё) сюда не входит: это предельное слово, строка `FIX` выше. «Много» — не частица `mult`, а форма `multu`.

## Имена

Имя пишется с заглавной буквы и не обязано склоняться.

| имя | примечание |
|---|---|
| Denis | имя человека; в реплике — узел, с которого говорят |
| K | имя капитана; в тексте часто `K.` |
| Solvell | Сатурн: sol + vell, «носящий кольцо света» |

## Числа

Счёт двоично-пятеричный: 2 и 5 — опоры, дальше умножение (`-`) и сложение (`+`). Значение в первой колонке — число, которое обязана давать запись.

| значение | запись |
|---|---|
| 0 | zult |
| 1 | nult |
| 2 | duut |
| 3 | dunult |
| 4 | du-duut |
| 5 | pant |
| 6 | pan+nult |
| 7 | pan+duut |
| 8 | pan+dunult |
| 9 | pan+du-duut |
| 10 | duut-pan |
| 12 | dunult-du-duut |
| 25 | pa-pan |
| 26 | pa-pan+nult |
| 28 | pa-pan+dunult |
| 100 | du-duut-pa-pan |
| 125 | pa-pa-pan |
| 130 | pa-pa-pan+pan |
| 135 | (pa-pan+duut)-pan |
| 625 | pa-pa-pa-pan |
| 3125 | pa-pa-pa-pa-pan |

Служебные куски, которые не бывают отдельным словом: `pan` (пять внутри выражения), `pa` (сокращённая левая копия пятёрки), `du` (сокращённая левая копия двойки). Отдельное «пять» — только `pant`, отдельное «два» — только `duut`. `zult` в составное число не входит.

## Композиты

Цитатная запись без слоя. В речи оба корня стоят в одном и том же слое; первая основа — вершина, вторая — родительский слой.

| основа | значение |
|---|---|
| mo-neb | дождь: вода, чей родительский слой — небо |
| neb-mo | водяное небо |
| mo-kor | река, вода земли |
| mo-mor | морская вода |
| knot-vedr | утро как узел |

`mo-mor` (морская вода, два корня через дефис) и `momor` (океан, одно слово) — разные узлы. В слое `-u-` это `mou-murt` и `momu`.
